# Application web installable (PWA)

## Pourquoi

L'app web doit pouvoir s'installer sur un téléphone (Android/iOS) et fonctionner hors ligne, comme une vraie application native.

## Ajouté

- `apps/web/public/manifest.webmanifest` : nom, couleurs, icônes, `display: standalone`.
- `apps/web/public/sw.js` : service worker — précache le shell de l'app à l'installation, supprime les anciens caches à l'activation, stratégie cache-first pour les assets statiques et network-first pour la navigation.
- Icônes PNG : `icon-192.png`, `icon-512.png` (générées depuis `favicon.svg`), `apple-touch-icon.png` (180×180 pour iOS).
- Plugin Vite `swVersionPlugin` dans `vite.config.ts` : remplace `__VERSION__` dans `sw.js` au build pour invalider le cache à chaque déploiement.

## Modifié

- `apps/web/index.html` : `<link rel="manifest">`, `<link rel="apple-touch-icon">`, balises `<meta>` PWA (theme-color, apple-mobile-web-app-*).
- `apps/web/src/main.tsx` : enregistre le service worker au chargement.
