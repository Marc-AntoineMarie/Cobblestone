# Journal des versions

Toutes les versions de Cobblestone et ce qu'elles changent. Ce fichier est complété par
`npm run release` à partir des messages de commit (voir [contribution/REGLES.md](contribution/REGLES.md)) ; le détail de chaque changement est dans [contribution/JOURNAL.md](contribution/JOURNAL.md).

Le format suit [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/) et les versions le
[versionnage sémantique](https://semver.org/lang/fr/).
